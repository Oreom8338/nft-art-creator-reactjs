## 📂 How to prepare your files

Keep your artwork sorted before you start.

Use one folder for each trait type, such as:

- Background
- Body
- Eyes
- Mouth
- Hat
- Accessories

Use clear file names so you can find and replace items with less effort. PNG files work best when you need transparent layers.

## 🧪 Best way to test your collection

Before you make 5,000 NFTs, generate a small batch first.

Try these steps:

1. Start with 10 to 20 NFTs
2. Check for missing layers
3. Look for overlaps that do not fit
4. Make sure rare traits appear at the right rate
5. Confirm the metadata matches each image

If the test batch looks right, move to a larger run.

## 🎯 Tips for better results

- Use the same canvas size for every layer
- Keep transparent PNG files for overlays
- Avoid long file names
- Group traits by type
- Save a backup of your source art
- Check rarity values before the final export

These steps help keep the output clean and easy to manage.

## 🛠️ If something does not look right

If your output looks wrong, check these items:

- layer order
- image size
- transparent backgrounds
- missing trait folders
- rarity values
- file names with special characters

A small mistake in one layer can affect the full batch, so it helps to review your setup before you run the generator.
