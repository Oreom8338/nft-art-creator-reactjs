## Instructions
- **Instructions on How to Use the NFT Art Creator:**
    - **Upload Base Images and Traits:**
        - Use the application interface to upload your base images and trait layers (e.g., backgrounds, accessories, etc.).
        - Ensure your traits are organized into folders for easier selection.
    - **Configure Rarity Levels:**
        - Assign rarity values to each trait to control how often they appear in the generated NFTs.
